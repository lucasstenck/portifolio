# Vigora — treino em casa (Android)
App Android (shell Kotlin + WebView, offline). 233 exercícios com animação vindos de `Desktop/exercicios`, 8 programas, player com cronômetro e descanso, diário com 5.193 alimentos das tabelas de calorias, progresso, conquistas.
APK: `dist/Vigora-debug.apk`. Assets: `node ../_tools/build-fit-assets.mjs`. Capturas em `screenshots/` (viewport 412x915). Dados de exemplo: `#/exemplo/inicio`.
