# Prestô — intermediação de serviços (Android)
App Android (offline) no modelo Airbnb/Uber: perfis, busca com filtros, agendamento por horário livre, pagamento protegido (valor retido até a conclusão, taxa de 12%), chat, avaliações e carteira. Modo profissional: pedidos, agenda e ganhos. APK: dist/presto-app.apk.
