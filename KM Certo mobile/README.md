# KM Certo — cálculo de corridas para motoristas e motoboys (Android)
App Android (offline). Calculadora com tarifa (bandeirada, km, minuto, espera, pedágio, noturno, bandeira 2, dinâmica), custo real por km, comissão, lucro líquido, veredito vale a pena, taxímetro, histórico, recibo, resumo do dia, relatórios, tarifas, veículos, abastecimentos, despesas e metas. APK: dist/kmcerto-app.apk.
