# Vetor — logística e entregas sob demanda (Android)
App Android (offline). Cotação por distância, veículo (moto, carro, van, baú), peso, expresso, ajudante e retorno; busca de motorista, rastreio, PIN de coleta, chat, comprovante com assinatura e avaliação; carteira, fatura, relatórios, rotas recorrentes e endereços. APK: dist/vetor-app.apk.
