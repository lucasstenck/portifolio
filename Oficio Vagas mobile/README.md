# ofício — vagas de emprego para candidatos e empresas (Android)
App Android (offline) com dois modos. Candidato: vagas com compatibilidade por habilidades, candidatura em 3 etapas, acompanhamento, mensagens e perfil. Empresa: painel com funil, publicar vaga, candidatos ranqueados, agenda de entrevistas e plano. APK: dist/oficio-app.apk.
